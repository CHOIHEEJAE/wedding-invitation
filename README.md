# 💍 모바일 청첩장 (Mobile Wedding Invitation)

최희재 ♥ 이혜진 — HTML · CSS · JavaScript 로 만든 모바일 청첩장입니다.
별도의 빌드 과정이나 설치가 필요 없는 **정적(static) 웹사이트**예요.

> 📌 **정적 사이트가 뭔가요?**
> 카페 벽에 붙인 포스터라고 생각하면 됩니다. 서버에서 매번 새로 그려주는 게 아니라,
> 이미 완성된 그림(HTML·CSS·JS)을 그냥 브라우저가 펼쳐 보여주는 방식이에요.
> 그래서 "실행"이라기보단 **"열어서 보는"** 것에 가깝습니다.

## 🚀 로컬에서 실행하는 방법

정적 사이트라 방법이 여러 가지예요. **아래로 갈수록 "실제 배포 환경과 비슷"** 해집니다.
가장 쉬운 1번부터 시도해 보세요.

### 방법 1. 그냥 파일 더블클릭 (가장 간단) ⭐️

`index.html` 파일을 **더블클릭**하면 기본 브라우저에서 바로 열립니다.
디자인·애니메이션·갤러리 스와이프는 이 방법만으로도 잘 동작해요.

```
Finder(맥) 또는 탐색기(윈도우)에서 index.html 더블클릭
```

> ⚠️ **주의 — 이 방법의 한계**
> 이때 주소창은 `file:///Users/...` 로 시작합니다. 이건 "내 컴퓨터 파일을 직접 연" 상태예요.
> 이 상태에서는 아래 두 가지가 **브라우저 보안 정책 때문에 막힐 수 있어요**:
> - 📋 **계좌번호 / 링크 복사** (`navigator.clipboard`) — 보안상 `https` 또는 로컬 서버에서만 허용
> - 💬 **카카오 공유 · 카카오맵** — 등록된 도메인에서만 동작
>
> **왜?** 브라우저는 "내 컴퓨터 파일(`file://`)"을 낯선 손님처럼 취급해서, 민감한 기능(복사·외부 연동)의 문을 잠가둡니다.
> 아래 2번처럼 **작은 로컬 서버**를 띄우면 주소가 `http://localhost` 가 되어, 브라우저가 "정식 웹사이트"로 대접하며 문을 열어줘요.

### 방법 2. 파이썬 내장 서버 (설치 불필요, 맥에 기본 탑재) ⭐️⭐️

터미널에서 이 폴더로 이동한 뒤 한 줄만 입력하세요.

```bash
# 이 폴더(index.html이 있는 위치)에서 실행
python3 -m http.server 5500
```

그다음 브라우저에서 접속:

```
http://localhost:5500
```

> 🍽️ **비유하자면** — 방법 1이 "냉장고 문 열고 선 채로 먹기"라면,
> 방법 2는 "작은 식당을 하나 차려서 제대로 상 차려 먹기"입니다.
> 브라우저가 진짜 웹사이트처럼 대접해줘서 복사·지도 같은 기능이 살아나요.
>
> 종료할 때는 터미널에서 `Ctrl + C` 를 누르면 됩니다.

### 방법 3. VS Code + Live Server 확장 (수정하며 볼 때 편함) ⭐️⭐️⭐️

코드를 고치면서 실시간으로 확인하고 싶다면 추천해요.

1. VS Code에서 이 폴더를 엽니다.
2. 확장(Extensions)에서 **Live Server** (author: Ritwick Dey) 설치
3. `index.html` 을 연 상태에서 우클릭 → **"Open with Live Server"**
   (또는 우측 하단 **"Go Live"** 버튼 클릭)

파일을 저장할 때마다 브라우저가 **자동으로 새로고침**돼요. 디자인 다듬을 때 아주 편합니다.

### 방법 4. Node.js 가 있다면 (npx)

```bash
npx serve
# 또는
npx http-server -p 5500
```

## 📱 모바일 화면으로 확인하기

이 청첩장은 **폭 480px 기준**으로 디자인된 모바일 전용 레이아웃이에요.
PC 브라우저에서도 화면 가운데에 모바일 크기로 예쁘게 보이지만,
실제 느낌을 보려면 **개발자도구의 모바일 모드**를 쓰세요.

1. 브라우저에서 `F12` (맥: `Cmd + Option + I`)
2. 좌측 상단 **기기 아이콘**(📱 Toggle device toolbar / `Cmd + Shift + M`) 클릭
3. 상단에서 iPhone 등 기기 선택

## ⚙️ 실제 청첩장으로 완성하려면 (선택 사항)

아래 값들은 지금 **샘플/미설정 상태**라, 실제로 쓰려면 채워 넣어야 합니다.

| 무엇을 | 어디서 | 지금 상태 |
|--------|--------|-----------|
| 카카오 JS 키 | `js/main.js` 의 `CONFIG.kakaoAppKey` | `YOUR_KAKAO_JS_KEY` (미설정) |
| 카카오맵 키 | `index.html` 의 `appkey=YOUR_KAKAO_MAP_KEY` | 미설정 |
| 예식장 좌표 | `js/main.js` 의 `CONFIG.venue` (lat/lng) | 서울시청 좌표(예시) |
| 지도 링크 | `CONFIG.kakaoMapUrl` / `naverMapUrl` | 미설정 |
| 갤러리 사진 | `images/gallery-01~05.jpg` | 우아한 그래픽 샘플 → 실제 사진으로 교체 가능 |
| 공유 썸네일 | `images/og-thumbnail.jpg` | 샘플 → 교체 가능 |

> 💡 카카오 키는 [Kakao Developers](https://developers.kakao.com) 에서 앱을 만들고
> JavaScript 키를 발급받으면 됩니다. (지도·공유 기능을 안 쓸 거면 설정 안 해도
> 나머지는 정상 동작해요 — 지도 자리엔 안내 문구가 대신 표시됩니다.)

## 🌐 인터넷에 올려서 공유하려면 (배포)

가장 간단하고 무료인 방법은 **GitHub Pages** 입니다.

1. 이 폴더를 GitHub 저장소(repository)에 올립니다 (`git push`).
2. 저장소 **Settings → Pages** 로 이동
3. Branch를 `main` / 폴더는 `/root` 로 지정 후 **Save**
4. 잠시 뒤 `https://<내아이디>.github.io/<저장소이름>/` 주소로 접속됩니다.

그 주소를 카카오톡으로 보내면 진짜 모바일 청첩장이 됩니다. 🎉

## 🖼️ 갤러리 사진 추가·교체하기

`images/` 폴더에 사진을 넣고, `index.html` 의 갤러리 부분에서 슬라이드를 복사해 붙이면 됩니다.

```html
<div class="swiper-slide">
  <img src="./images/내사진.jpg" alt="갤러리" />
</div>
```

> 세로 사진(3:4 비율)이 가장 예쁘게 들어맞아요.
